## 命名規則

```
<類型>-<主題>-v<版號>.<md|html>
```

| 類型 | 用途 | 例 |
|---|---|---|
| `設計提案` | 需要 PM 決策的方向性提案 | `設計提案-視覺方向-v1.md` |
| `設計規格` | 方向定案後的實作依據 | `設計規格-Theme-v1.md` |
| `設計驗收` | 實作完成後的前後對照與檢查表 | `設計驗收-S2轉盤-v1.md` |
| `PM決策`／`PM核可` | PM 對設計交付物的裁示 | `PM核可-設計規格Theme-v1.md` |

版號只在**內容有實質改變**時進位。修錯字、補說明不進位。舊版不刪除，保留討論脈絡。

**規格被指正時不要靜靜改掉** —— 在原處留下錯誤紀錄與正確版本，
否則下一個人可能照舊稿又改壞一次（已發生兩次，見 S2 規格第四節）。

|---|---|
