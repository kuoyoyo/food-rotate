## 二、`make-icon.swift` 依規格第二節改寫

### 照著做的

| 項目 | 結果 |
|---|---|
| 背景 | 淡橘漸層 → `Dark.pageBackground` 實色滿版 |
| 中心圓 + 刀叉 | **刪掉** |
| 外圈白色描邊 | **刪掉** |
| 分隔線 | **新增**六條，色 = 背景色，寬 `0.016 S` |
| 指針 | 依比例重畫，**兩層**：先背景色三角切缺口，再內縮 `0.012 S` 的 `sauce` 三角 |
| 幾何 | 全部以 `S` 的比例寫，照抄規格 |
| 去色版 | **同一段繪製函式**，只換一個 `Palette` 參數 |

**沒有把 SVG 丟進 catalog。** 生產路徑維持腳本，理由就是你提醒的那個 ——
色值烙進 SVG 之後改色盤 icon 又會跟 App 分岔。腳本讀 `DesignTokens`，
六格走 `slotOrder(for: 6)` 再套加深公式，跟 App 內 6 格轉盤是同一組色。

### 指針兩層的必要性

我照規格做了，也理解為什麼：第一格是辣椒紅、指針是 `sauce`，兩個都是暖紅。
只畫一層的話指針會跟第一格黏成一片。先用背景色切一個缺口，再把主色三角放進缺口裡，
邊界才出得來。

### 進 catalog

`AppIcon.appiconset` 現在有兩張：

```
AppIcon.png          彩色
AppIcon-Tinted.png   去色（appearances: luminosity / tinted）
```

去色版**自己給**而不是讓系統自動去色，理由照規格第四節 —— 自動去色的結果我們控制不了。
