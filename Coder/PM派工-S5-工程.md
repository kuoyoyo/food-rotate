## 〇-A、「以後都不要」要二次確認（kuoyo 2026-08-12 指定）

### 要求

> 「以後都不要」需要雙重確認，不要一次就確認。

現況：候選清單的 `⋯` Menu 裡點一下就直接寫進排除名單。

### 為什麼這是對的

App 裡的動作分兩種：**這一輪的**與**永久的**。

| 動作 | 範圍 | 復原 |
|---|---|---|
| 這輪不要 | 這一次抽樣 | 換一組就回來了 |
| **以後都不要** | **永久** | 要自己去「設定 → 我的清單 → 以後都不要的」找回來 |

兩個現在**都在同一個 Menu 裡、都是點一下**，只有紅字之差。手滑點錯下面那個，
那道菜就從此不再出現，而且使用者未必知道去哪裡救。

**`role: .destructive` 只改顏色，不改後果。**

### 做法

用系統的 `confirmationDialog`，不必等設計：

| 項目 | 內容 |
|---|---|
| 標題 | 「以後都不要「滷肉飯」？」 |
| 說明 | 「這道菜不會再出現在轉盤上。可以在設定的『我的清單』裡改回來。」 |
| 確認鈕 | 「以後都不要」，`role: .destructive` |
| 取消鈕 | 「取消」 |

**說明那句要講出救回來的路徑** —— 永久性動作要讓人知道它不是不可逆的，
這跟「放寬要老實說明」是同一條原則：後果要講出來。

### 「這輪不要」不要加確認

它是可逆的、而且是最常用的一個（左滑快捷就是為它做的）。
**加確認會把最常用的動作變慢，去換一個不存在的風險。**

兩個動作的份量不同，這正是要區分開來的理由。

## 一、先做：`reduceMotion` 的實測

S3 的規格定義了完整的降級行為（`設計規格-結果頁-v1.md` 五-5），你實作了，
但一路列在「已實作，未實測」到現在。**這是 S1–S4 唯一沒被實機確認過的功能。**

要驗的五項：

| 對象 | `reduceMotion` 開啟時應該 |
|---|---|
| 圖示轉場 | **取消** `matchedGeometryEffect`，hero 直接以 76pt 出現 |
| Sheet | 改 `opacity` 淡入 0.15s，不是由下推入 |
| 背景壓暗 | 同樣淡入 0.15s |
| 中選格高亮 | **只加粗描邊，不放大** |
| 下拉關閉 | **保留跟手**（那是直接操作，不是動效） |

設定路徑：模擬器「設定 → 輔助使用 → 動態效果 → 減少動態效果」。
**這個你自己就能開**，不需要觸控之外的工具 —— 開完之後轉一次盤看結果頁。

若有不符規格的，一併修掉再報。
