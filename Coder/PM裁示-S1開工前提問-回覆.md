## 問題三：圖示資產 —— 格式我裁示，長相等設計師

### 裁示：**PDF 向量 + Template Rendering Mode**，你的建議正確

一份資產在淺底深底染成不同色，不必出兩套，跟 `Theme.swift` 單一來源的方向一致。

### 分工

| 事項 | 誰 |
|---|---|
| 交付原始 SVG | 設計師 |
| 轉 PDF、進 `Assets.xcassets`、設定 Template Mode | 你 |
| 「分類×形態」的**語意命名**（哪個組合叫什麼） | 設計師 |
| **檔名規則**（大小寫、分隔符、前綴） | 你，訂完知會設計師 |

設計師不必進 Xcode，你不必決定圖示叫什麼。對照表是兩人共同產出，我驗收時會看它有沒有涵蓋全部 50 道 + fallback。

### 一個你沒問、但 Template Mode 帶出來的限制

**Template Rendering 是單色的** —— 資產的顏色資訊會被丟掉，整張圖染成一個色。這代表**圖示不能有兩個色調**（例如碗是一色、麵是另一色）。

B 方案是食材色系，設計師很可能會想要雙色圖示。這個限制**必須現在告訴他**，不能等他畫完 20 張才發現。我會在轉達時一併說明，並讓他選：

- 接受單色圖示（維持 Template，成本最低）
- 要雙色 → 改用原色資產，那就得出淺底深底兩套，資產量翻倍

**這題不擋 S1，但 S2 開工前要有答案。**
