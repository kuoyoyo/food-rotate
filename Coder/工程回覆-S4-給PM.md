## 二、做了什麼

| 項目 | 說明 |
|---|---|
| `FlowLayout` | 自訂 `Layout`。不用 `LazyVGrid` —— 固定欄寬會讓「台式」跟「麵包餅皮」一樣寬，34 個標籤擠不進一屏 |
| `TagChip` | 四種狀態。選中一律**實心填色**，不是染底 |
| `TagGrid` | 篩選器與新增料理表單**共用同一個元件**，差別只有 `emphasizesRestriction` 一個旗標 |
| `FilterBar` | 展開態改網格，忌口區染 `noticeSurface` + 警示標題 + 淺色邊框 |
| 候選清單 | 高密度列：單一容器、44pt 列、縮排分隔線、24pt 線稿圖示、`TagBadge` 角標、`⋯` Menu、左滑「這輪不要」 |
| `FoodEditorView` | 換成同一個 `TagGrid`，`emphasizesRestriction: false` |

### 沒有復用 `TagBadge` 做 chip

照你核可的那條界線。長得一樣不代表是同一個東西 —— `TagBadge` 沒有 `Capsule`、
沒有選中態、不吃點擊。**共用的是顏色 token，不是元件。**

### 「這輪不要」的產品規則在兩個入口都守住

Menu 與左滑都掛在同一個 `canDelete`（候選 > 2）。轉盤最少要留 2 格才轉得起來。

## 五、兩件想請你注意的

### 1. 「一屏看完」是在預設字級下成立

實機確認 34 個標籤一屏看得完，但那是**預設 Dynamic Type**。
規格說放大時允許捲動，我沒有另外做限制 —— 放大就是自然捲動，無障礙優先於版面。
你驗收時若想看放大後的樣子，那是**未實測**的狀態。

### 2. 忌口的「一定不會出現」那句小字我留著了

規格說整區染色之後「不會被自動放寬」從外觀就看得出來。我同意，但**沒有把那句話拿掉**：
外觀說的是「這一區不一樣」，那句話說的是「哪裡不一樣」。
兩者不重複，而且那是產品規則第一條在畫面上的唯一說明。要拿掉的話請明講。
